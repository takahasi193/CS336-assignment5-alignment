# GSM8K Prompting 基线评测报告：question_only

* **模型 (Model)**: `allenai/OLMo-2-0425-1B` (Base Model)
* **评测数据集 (Dataset)**: GSM8K 测试集 (`data/gsm8k/test.jsonl`)，共 1,319 道小学数学应用题
* **提示词形式 (Prompt)**: `question_only`
  ```text
  {question} Please put your final answer within \boxed{}.
  ```
* **采样超参数 (Sampling Parameters)**:
  * `temperature`: 1.0
  * `max_tokens`: 512
  * `n`: 1
  * `seed`: 42
  * `stop`: 未设置 (按作业要求，question_only 不设终止标签)
* **判卷函数 (Grader)**: `cs336_alignment.drgrpo_grader.question_only_reward_fn`

## 3. 样本质检与误差分析 (Error Analysis - Problem a)

通过对生成结果日志的深入抽查，分析如下：

### (1) Type 1 样本深度拆解（仅有的 2 个成功案例）
* **案例一（预算邀请好友题）**：
  * **表现**：模型生成了严重的逻辑幻觉（如凭空出现未提及的人名 Donnie/Mandy，列出毫无依据的代数式），但在末尾输出了 `within \boxed{2.}`。
  * **结论**：**纯属巧合的随机蒙对（Lucky Guess）**。题目答案恰好是一个极小的正整数 2，模型在自发发散中撞对了答案。
* **案例二（学生筹款代数题）**：
  * **表现**：模型成功激活了**自发的思维链（Spontaneous CoT）**，明确设定未知数 $m$，列出一元一次方程 $50,000 + 20m = 175,000$，并一步步移项、除法得出正确答案 $6250$。
  * **缺陷**：得出答案后，由于没有配置终止标签，模型陷入严重的**尾部退化与复读死循环（Repetition Degeneration）**，不断重复 `$$6250\boxed{$6250}...`。
  * **结论**：证明了基座模型内部具备多步符号推导的潜力，但缺乏结束生成的意识。

### (2) Type 2 抽查观察（10+ 例）
* **表现特征**：模型生成了 `\boxed{}`，但内部为空或者填入了无关的表达式、错误数字；随后大多开始复读预训练语料中的题库元数据、网页链接或论坛页脚（如 `"Similar Puzzles"`, `"Share your Results"`）。
* **误判情况**：在抽查的样本中，**未发现**“其实做对了但因 Parser 故障被判错”的个案。模型确实未正确解题。

### (3) Type 3 抽查观察（10+ 例）
* **表现特征**：
  1. **直接输出空字符串 `""`（高频现象）**：基座模型面对问句 prompt，在第一个 token 即输出了 `<|endoftext|>` 结束符，直接放弃作答。
  2. **扮演题库生成器**：模型看到问题后，自动补全后续题目（自发生成 `question 2:`、`question 3:`）或吐出无意义的代码片段。
* **误判情况**：类别 3 中**不存在**算对的情况。

## 4. 模型行为特征总结 (Model Behavior - Problem b)

1. **仅提供问题是否足够？**
   * **完全不够**。纯 Base Model 本质上仅在做无监督的 Next-Token 补全，没有“作为助手解答用户问题”的指令对齐能力，直接提问的答题成功率仅为 0.15%。
2. **缺乏推理稳定性与停止意识**：
   * 模型极易早停（交白卷）或过度发散（复读、续写题库、死循环）。
3. **对强化学习（RL）的启发**：
   * 尽管整体准确率极低，但 Type 1 案例二证明了基座模型内部已经具备方程列式与分步演算的知识储备。后续的 RL（如 GRPO）的核心任务正是要强化这种罕见的正确推理行为，抑制幻觉与退化模式。
